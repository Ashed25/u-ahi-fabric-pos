ဦးအဟိ အထည်ဆိုင် — ရောင်းနည်း

🔒 စဝင်ရင် ကိုယ့် PIN ဂဏန်း ၄ လုံး ကို နှိပ်ပါ။ မသေချာရင် သားသမီး / ပိုင်ရှင်ကို ခေါ်ပါ။

၁အထည် ရောင်းနည်း

  1. စာကပ်ပေါ်က ဘားကုဒ်ကို စကန်ဖတ်ပါ။ “တီ” အသံ ကြားရမည်။
  2. ပစ္စည်းနဲ့ ဈေး စာရင်းထဲ ပေါ်လာမည်။ နောက်တစ်ထည် ထပ်စကန်ပါ။
  3. မှားသွားရင် အနီရောင် “နောက်ဆုံးတစ်ခုဖျက်” ကို နှိပ်ပါ။

၂ပိတ်စ ရောင်းနည်း

  1. ပိတ်စ ဘားကုဒ်ကို စကန်ဖတ်ပါ။ အလျား ထည့်ရန် စာမျက်နှာ ပွင့်မည်။
  2. ဖြတ်မည့် အလျားကို + ကိုက်၊ + တောင်၊ + ထွာ … နှိပ်ပြီး ထည့်ပါ (ဥပမာ ကိုက် ၂ ခါ + ထွာ ၁ ခါ = ၂ ကိုက် ၁ ထွာ)။ မှားရင် −။
  3. အောက်မှာ ဈေး ကြီးကြီး ပြမည်။ မှန်ရင် အစိမ်း “အိုကေ”။

၃ငွေရှင်းနည်း

  1. အစိမ်း “ငွေရှင်းရန်” ကို နှိပ်ပါ။
  2. ငွေသား — ဖောက်သည် ပေးသော ငွေစက္ကူ ခလုတ် (+၅,၀၀၀ / +၁၀,၀၀၀ / +၂၀,၀၀၀) ကို နှိပ်ပါ။ ပြန်အမ်းငွေ အစိမ်းရောင် ကြီးကြီး ပြမည်။ KBZPay / WavePay ဆိုရင် ထိုခလုတ်ကို ရွေးပါ။
  3. “ပြီးပြီ” → ပြန်အမ်းငွေ ပေးပြီး → “နောက်တစ်ယောက်”။

၄စကန် မဖတ်ရင်

  1. “ဒီပစ္စည်း မတွေ့ပါ” ပြရင် “ဓာတ်ပုံဖြင့် ရွေးရန်” ကို နှိပ်ပါ။
  2. ပစ္စည်း ဓာတ်ပုံကို နှိပ်ပါ။ (အပေါ်က ကွက်ထဲမှာ အမည် (သို့) ဘားကုဒ်စာအုပ်က ဂဏန်း ရိုက်ရှာလည်း ရသည်)
  3. စာကပ် ပြုတ်နေရင် ပိုင်ရှင်ကို ပြောပါ — စာကပ် အသစ် ထုတ်ပေးမည်။
