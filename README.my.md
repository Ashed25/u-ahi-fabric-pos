# ဦးအဟိ အထည်ဆိုင် — ရောင်းချမှု စနစ် (POS) လမ်းညွှန်

- **အက်ပ်:** https://ashed25.github.io/u-ahi-fabric-pos/
- **ရောင်းသူများအတွက် ပုံပါ လမ်းညွှန် (A4 တစ်မျက်နှာ):** https://ashed25.github.io/u-ahi-fabric-pos/guide.html
- English: [README.md](README.md)

## ပထမဆုံး စတင်ခြင်း

1. အက်ပ်ကို ဖွင့်ပါ။ **ပိုင်ရှင်** အကောင့် ဖန်တီးခိုင်းမည်: အမည်၊ PIN ဂဏန်း ၄ လုံး၊ စကားဝှက် (၆ လုံး အနည်းဆုံး — ဆက်တင်၊ အသုံးပြုသူ၊ Excel ထည့်ခြင်း၊ အရန်၊ စာရင်းစစ် မှတ်တမ်း အတွက်)။ **စကားဝှက်ကို စာရွက်ပေါ် ရေးမှတ်ထားပါ** — မေ့သွားလျှင် ပြန်ယူ၍ မရပါ။
2. **မီနူး → 👥 အသုံးပြုသူများ** — လူတိုင်းကို ကိုယ်ပိုင် PIN ဖြင့် ထည့်ပါ။ မိဘများကို **ရောင်းသူ** အဖြစ် ထည့်ပါ။
3. **မီနူး → ⚙️ ဆက်တင်များ** — လိပ်စာ၊ ဖုန်း၊ ငွေပေးချေနည်းများ၊ ပိတ်စ ဈေး ပြည့်ကိန်း (၅၀ ကျပ်)၊ ပြေစာ (ပုံမှန် ဖွင့်ထား)၊ CT (ပုံမှန် ပိတ်ထား)။
4. ပစ္စည်းများ ထည့် → စာကပ် ထုတ် → **လက်ကျန် စစ်ရန်** ဖြင့် စတင် လက်ကျန် ထည့်ပါ။
5. အရင် စမ်းကြည့်လိုလျှင် **မီနူး → နမူနာ ပစ္စည်း ထည့်ရန်**။ ပြီးလျှင် **နမူနာ ပစ္စည်း ဖျက်ရန်**။

## ရာထူး (အခွင့်အရေး)

| ရာထူး | လုပ်နိုင်သည် |
|---|---|
| ရောင်းသူ (မိဘများ) | ရောင်းခြင်း၊ ခဏထားခြင်း၊ ယနေ့ အနှစ်ချုပ်၊ အရောင်း မှတ်တမ်း |
| မန်နေဂျာ | အထက်ပါ + ပြန်လဲ/ပြန်အမ်း၊ ပယ်ဖျက်၊ လက်ကျန်၊ ပစ္စည်း/ဈေး၊ စာကပ်၊ အစီရင်ခံစာ၊ လျှော့ဈေး |
| ပိုင်ရှင် | အားလုံး + ဆက်တင်၊ အသုံးပြုသူ၊ Excel ထည့်ခြင်း၊ အရန်/ပြန်ယူ၊ Cloud၊ စာရင်းစစ် မှတ်တမ်း |

ရောင်းသူက ပြန်အမ်း/ပယ်ဖျက် လုပ်ရန် လိုလျှင် မန်နေဂျာ (သို့) ပိုင်ရှင်က တက်ဘလက်ပေါ်တွင် PIN ရိုက်ပေးရမည်။ ဘယ်သူ ခွင့်ပြုသည်ကို မှတ်ထားမည်။ ၅ မိနစ် မသုံးလျှင် အလိုအလျောက် သော့ခတ်မည် (🔒)။

## တက်ဘလက်ပေါ် ထည့်ခြင်း

1. Android တက်ဘလက်ရှိ **Chrome** တွင် အက်ပ်လင့်ကို ဖွင့်ပါ။
2. ⋮ → **Add to Home screen / Install app**။ အင်တာနက် မရှိလည်း သုံးနိုင်သည်။

## ဘားကုဒ် စကန်နာ ချိတ်ခြင်း

- စကန်နာကို **USB / Bluetooth keyboard (HID)** အနေအထားဖြင့်၊ စကန်ပြီးတိုင်း **Enter** ပို့အောင် ထားပါ (စကန်နာ အများစု ပုံမှန် ဒီအတိုင်း)။
- Android Bluetooth ဆက်တင်တွင် တွဲပါ (သို့) USB-OTG ဖြင့် ထိုးပါ။
- **မီနူး → 🔍 စကန်နာ စမ်းရန်** — စာကပ်တစ်ခု စကန်ဖတ်ပါ။ “တီ” အသံနဲ့ ပစ္စည်း အမည် ပေါ်ရမည်။ တက်ဘလက်တွင် မြန်မာ ကီးဘုတ် ဖွင့်ထားလည်း အဆင်ပြေသည်။
- **စကန်နာ မရှိလျှင်:** “ဓာတ်ပုံဖြင့် ရွေးရန်” ထဲတွင် ဘားကုဒ် နံပါတ် (သို့) အမည် ရိုက်ရှာပါ၊ (သို့) **📷 ကင်မရာဖြင့် ဖတ်ရန်**။

## ပစ္စည်း ထည့်ခြင်း

- **တစ်ခုချင်း:** မီနူး → 👕 ပစ္စည်းများ → ပစ္စည်းအသစ်။ *တစ်ထည်ချင်း* (အရွယ်/အရောင် တစ်ခုစီ ဘားကုဒ် ကိုယ်စီ) (သို့) *အလျားဖြင့်* (ကိုက်/တောင် စသည် ဈေး၊ အနံ၊ အမြန်ရွေး အလျားများ)။ ဓာတ်ပုံ ရိုက်ပါ။
- **အများကြီး (၅၀၀ ခန့်):** မီနူး → 📥 Excel မှ ထည့်ရန် → **Excel ပုံစံ** ဒေါင်းလုဒ် → ပစ္စည်းတစ်ခု (အရွယ်/အရောင် တစ်ခု) တစ်ကြောင်း ဖြည့် → ဖိုင် ရွေးပါ။ အမှား ရှိလျှင် အတန်း နံပါတ်ဖြင့် ပြမည်။ ဘားကုဒ်များ အလိုအလျောက် ထုတ်ပေးမည်။

## ဘားကုဒ် စာကပ် ထုတ်ခြင်း (လက်ပ်တော့မှ)

1. လက်ပ်တော့ထဲ အချက်အလက် ရှိရန် — Cloud ချိတ်ပါ (လက်ပ်တော့ကို **ကြည့်ရန်သာ**) (သို့) တက်ဘလက်မှ အရန်ဖိုင်ကို လက်ပ်တော့တွင် ပြန်ယူပါ။
2. **မီနူး → 🏷 ဘားကုဒ် စာကပ် ထုတ်ရန်** → **40×30** / **50×30** (စာကပ် ပရင်တာ)၊ **A4 စတစ်ကာ**၊ (သို့) **ဘားကုဒ် စာအုပ်** (ဓာတ်ပုံပါ A4 — ကောင်တာမှာ ထားရန်)။
3. အမျိုးအစား၊ အရေအတွက် ရွေး → ကြိုကြည့် → ပရင့်။ ပရင့် ဝင်းဒိုးတွင် **Scale 100%**၊ **Margins: None** ရွေးပါ။

## နေ့စဉ်

- **ရောင်းနည်း** — [ပုံပါ လမ်းညွှန်](https://ashed25.github.io/u-ahi-fabric-pos/guide.html) ကို ပရင့်ထုတ်ပြီး ကောင်တာမှာ ကပ်ထားပါ။
- **📊 ယနေ့ အနှစ်ချုပ်** — အရောင်း၊ ငွေပေးချေနည်း အလိုက်၊ ပြန်အမ်း၊ ရောင်းခဲ့သော ပစ္စည်း၊ မနေ့/ပြီးခဲ့သည့် အပတ်နှင့် နှိုင်းယှဉ်။
- **ပြန်လဲ/ပြန်အမ်း** — အရောင်း မှတ်တမ်း → အရောင်း ဖွင့် → ↩ ပြန်လဲ / ပြန်အမ်း။

## အစီရင်ခံစာနှင့် Excel

- **မီနူး → 📈 အစီရင်ခံစာ** — နေ့/အပတ်/လ/သုံးလပတ်/ဘဏ္ဍာနှစ် (ဧပြီ–မတ်)၊ အမြတ် (ပစ္စည်းတွင် အရင်း ထည့်ထားလျှင်)၊ အရောင်းရဆုံး၊ **⬇ Excel**၊ **စာရင်းကိုင်အတွက် အချက်အလက် အားလုံး**။
- **ကုန်သွယ်လုပ်ငန်းခွန် (CT)** — သုံးလပတ် အလိုက် အစီရင်ခံစာ၊ Excel။ ၁၂ လ အရောင်း ၅ ကုဋေ၏ 80% / 100% ရောက်လျှင် သတိပေးမည်။ နှုန်းထားကို စာရင်းကိုင်နှင့် အတည်ပြုပါ။

## အရန် သိမ်းခြင်းနှင့် Cloud

**အရန်ဖိုင်:** မီနူး → 💾 အရန်သိမ်းရန် → *အရန်ဖိုင် သိမ်းရန်* → Google Drive / Viber သို့ ပို့ပါ။ တစ်ရက်ထက် ကြာလျှင် မီနူးတွင် သတိပေးမည်။

**Cloud (Supabase — အခမဲ့):** အင်တာနက် ရသည့်အခါ စက္ကန့် ၃၀ တိုင်း အလိုအလျောက် ပို့မည်။

1. [supabase.com](https://supabase.com) တွင် အကောင့်ဖွင့် → New project (Region: Singapore)။
2. SQL Editor → **မီနူး → ☁️ Cloud** ထဲက SQL ကို ကူးထည့် → Run။
3. Authentication → Users → **Add user** (email + စကားဝှက်၊ Auto Confirm ဖွင့်)။
4. Project Settings → API → **Project URL** နှင့် **anon public** key ကူးပါ။
5. **ဆိုင်တက်ဘလက်** တွင်: ☁️ Cloud → ထည့် → **ချိတ်ဆက်မည်** → **ဆိုင်က တက်ဘလက်**။
6. **လက်ပ်တော့/ဖုန်း** တွင်: အလားတူ ချိတ် → **ကြည့်ရန်သာ**။ ပြီးလျှင် ဆိုင် PIN ဖြင့် ပြန်ဝင်ပါ။
7. **တက်ဘလက် ပျက်လျှင်:** တက်ဘလက် အသစ်တွင် အက်ပ် ထည့် → ယာယီ ပိုင်ရှင် ဖန်တီး → ☁️ Cloud ချိတ် → **ပျက်သွားသော တက်ဘလက် အစား ဒီစက်ကို သုံးမည်**။ အရောင်း နံပါတ်များ ဆက်လက်မည်။

Supabase အခမဲ့ project ကို **၇ ရက် မသုံးလျှင် ခဏ ရပ်ထား** တတ်သည် (ရုံးပိတ်ရက် ရှည်ကြာလျှင်)။ အက်ပ်က ဆက်ရောင်းနိုင်သည် — supabase.com တွင် ဝင်ပြီး **Restore project** နှိပ်ပါ။ စောင့်နေသော အချက်အလက်များ အလိုအလျောက် ပို့မည်။
